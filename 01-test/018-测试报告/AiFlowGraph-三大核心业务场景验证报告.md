## 一、验证背景与测试方法论

根据真实中大型数字化企业在**审批管理**、**智能服务**与**数据处理**三大领域的典型业务需求，本报告围绕 AiFlowGraph 系统的核心三范式（状态流 State Flow、控制流 Control Flow、数据流 Data Flow）设计了 3 个大型综合业务场景。

本轮验证严格遵循**“从 Web 界面上操作，而不是 API 调用”**的原则：
1. 全程由自动化浏览器程序真实加载 DOM，模拟用户在网页上的鼠标点击、表单录入、弹窗确认、标签页切换及画布节点操作；
2. 捕获页面实际网络请求、响应状态码、Vue/React 状态更新、Toast 轻提示及元素禁用状态；
3. 验证业务规则在真实界面层的约束效果（如不可变发布保护、输入必填拦截、多维度查询过滤联动等）。
