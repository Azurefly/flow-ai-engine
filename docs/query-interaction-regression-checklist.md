# 查询状态与页面交互回归验收清单

> 用途：每次前端查询、页面壳层或请求频率调整后执行。清单只验证用户可见行为和请求边界，不要求修改 API 契约，也不通过浏览器控制台注入数据绕过权限。

## 0. 运行前置与证据

- [ ] 记录提交版本、浏览器、视口（桌面 `1280×800`，窄屏 `375×812`）和测试账号权限范围。
- [ ] 使用仅包含当前账号授权项目/流程的会话；不得借用其他用户数据或直接调用未授权资源。
- [ ] 清空浏览器 Network/Console，硬刷新一次，保存首次请求与失败响应证据（状态码、`content-type`、请求数量）。
- [ ] 运行 `pnpm check`；再运行 `pnpm exec vitest run --config vitest.unit.config.ts server/workflow-ui-regression.test.ts`。

## 1. 首屏与请求频率边界

- [ ] 首屏认证查询未完成时显示明确的加载反馈，不显示“暂无项目”、零计数或错误空态。
- [ ] 登录后控制台初次加载只请求当前首屏需要的 `auth.me`、公开配置和授权项目/流程数据；非活动设计器、IAM、数据资源查询不得提前汇入首屏批量请求。
- [ ] 在首屏稳定后观察至少 15 秒：只有源码明确声明的轮询查询产生周期请求；无重复挂载导致的成倍请求、无每次渲染新增请求。
- [ ] 页面切换到流程仓库、已启动流程、系统配置后，新增请求只属于目标页面；返回原页面不会产生无限增长的查询请求。
- [ ] 刷新按钮只触发一次对应查询失效/重取，不改变 URL 中的授权数据，不触发 mutation。
- [ ] 查询失败响应（尤其网关 HTML/非 JSON 响应）应显示可读错误原因，不应出现未处理 JSON 解析异常覆盖页面。

## 2. 业务中心与项目工作区

- [ ] 项目查询初载显示加载反馈；成功空列表显示“暂无可访问业务项目”类明确空态，失败显示原因和“重试”。
- [ ] 关键词、创建时间筛选在点击查询后生效；重置清空草稿与已应用条件。查询中不得把旧数据误替换成无结果空态。
- [ ] 切换项目后，流程筛选、新建流程、选中流程/详情状态均清理；前一项目名称、流程或权限数据不残留。
- [ ] 项目流程查询初载显示“正在读取项目流程”；失败显示错误原因与重试；成功零条显示当前项目暂无匹配流程。
- [ ] 流程列表的详情、设计、发起/启动、审核/发布操作按状态和权限显示；禁用按钮有原因提示，不发起无效请求。

## 3. WorkflowWarehouse 流程仓库

- [ ] 项目仓库查询初载显示读取中反馈；失败显示服务端原因及“重试”，失败期间不得显示根目录或“该目录暂无流程”空态。
- [ ] 归档模式切换后，`archivedWorkflows` 查询初载显示读取中；失败显示具体原因及“重试”，失败期间不得显示“当前项目暂无可恢复归档流程”。
- [ ] 成功且无归档流程时才显示归档空态；成功且目录无流程时才显示目录空态。
- [ ] 关键词命中子目录时保留父目录路径；无命中显示“没有搜到任何数据”，不误报查询失败。
- [ ] 选择流程后右侧详情加载、无详情空态和只读画布均有明确状态；切换项目后选中目录、流程、勾选项和关键词清理。
- [ ] 导入、导出、归档、目录操作按钮在无权限/无选中对象时保持禁用或显示原因，不触发 API。

## 4. RunCenter 运行中心

- [ ] 未选择流程时显示引导空态；选择流程后运行、指标和告警查询各自进入加载态。
- [ ] 任一关键查询失败时显示失败原因和“重试”；告警失败不得显示“当前筛选范围内没有失败告警”。
- [ ] 指标查询加载中或失败时，总运行、成功、失败、失败率、平均耗时均显示 `—`/不可用，不显示 `0` 冒充真实指标。
- [ ] 运行列表初载显示读取中；失败显示原因+重试；成功零条才显示筛选范围空态。
- [ ] 清除筛选只清除本地筛选条件并触发既有查询；运行详情选择、暂停、恢复、取消、终止按钮按状态显示并正确禁用 pending 状态。
- [ ] 失败告警仅在告警查询成功后显示零未读空态；标记已读只触发对应 mutation，成功后告警列表刷新。

## 5. ProcessWorkbench 已启动流程

- [ ] 看板首次读取显示“正在读取已启动流程/当前授权范围”反馈；失败显示原因+重试；成功零条才显示“暂无可见流程任务”。
- [ ] 日历首次读取显示加载中；失败显示原因+重试；成功无事件时保留可切换月份的日历，不把空事件误报查询失败。
- [ ] 待办、已办列表首次读取显示加载行；失败显示原因+重试；成功零条显示筛选条件下暂无任务。
- [ ] 我发起、全部流程实例列表首次读取显示加载行；失败显示原因+重试；成功零条显示暂无流程实例。
- [ ] 左侧导航切换只清理局部选中状态并使必要查询失效；不会重复挂载所有查询，也不产生频率之外的后台请求。
- [ ] 打开实例详情页签显示详情加载中；无权/不存在显示服务端原因+重试；成功无节点时显示明确空态；关闭/返回不改变任务或运行状态。
- [ ] 批量领取/处理、移交、退回和单项操作只在有选中对象且权限/状态满足时可用；pending 时按钮禁用并显示进行中反馈。

## 6. 窄屏、可访问性与错误恢复

- [ ] `375×812` 下页面主体不横向溢出；宽表格在自身容器内横向滚动，加载/错误/空态文案不被截断。
- [ ] 加载状态使用 `role="status"`/`aria-live`，错误状态使用 `role="alert"`；重试按钮可键盘聚焦并有可读名称。
- [ ] 重试成功后错误面板消失并显示数据/成功空态；连续失败不会叠加多个错误面板或重复 toast。
- [ ] Network 中确认重试只重取失败查询；不改变请求参数、轮询间隔、API 响应结构或 mutation payload。
