## 本轮新增修复

1. **定义输入校验加固。** `validate` 现在拒绝未知节点类型、非法位置、数组/空配置和悬挂连线，避免无效 JSON 进入执行引擎。
2. **授权错误语义收敛。** 成员授予中的业务输入问题以 `BAD_REQUEST` 返回，和认证失败、资源拒绝路径保持可区分语义。
3. **历史运行记录兼容。** `workflow.runDetail` 接受受限长度的运行 ID，而非仅 UUID；旧随机字符串 ID 可在运行中心加载详情和节点日志。
4. **流程创建可用性。** 流程仓库“新建”按钮现显式提交所属表单，浏览器级验收确认可创建并进入设计器。
5. **已登录窄屏布局。** 控制台壳层、侧栏、设计器和画布调整为移动优先单列，在 `md`/`lg` 断点恢复桌面结构。
