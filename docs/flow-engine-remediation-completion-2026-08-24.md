## 3. 本轮关键安全规则

1. 人工操作必须同时满足：流程实例处于可操作状态、任务处于当前状态、任务仍在用户可执行操作集合中、账号启用、用户是当前任务所有人。
2. `claimed` 任务只认 `claimedByUserId`；候选人和管理员都不能替代当前领取人提交。
3. 批量处理逐项调用相同的服务端授权链，不共享一次性前置授权，也不跨项目或跨流程放行。
4. 部门角色授权不复制到个人记录；成员通过组织关系实时继承，解绑、失效或账号停用后实时失效。
5. 发布后的执行使用不可变计划；子流程使用发布时快照，避免运行中被后续编辑漂移。
6. HTTP 连接使用预解析并固定的公网地址；TLS 仍按原 hostname 校验，重定向不自动跟随。
7. 数据源创建和配置变化不能伪造“已验证”；真实连接测试尚未实现前保持草稿状态。
