# 组织架构独立管理页实施计划（2026-08-23）

## 目标与边界

- 从流程引擎“系统配置 → 组织架构”进入独立安全子路由 `#/system/organization`，并可明确返回系统配置。
- 组织页、流程处理人解析和 IAM 复用当前项目同一套 MySQL 表，不连接或依赖原 BDP 服务。
- 仅参考 BDP 4.4.22 的业务契约、字段、交互和视觉证据；不复制原 Java/JSP/SeaJS 层级，不引入其内部 JAR。
- 所有新增入口均为“按钮 → 弹窗 → 真实 tRPC mutation”；取消不写库，提交失败保留输入，成功后关闭、清理并刷新。

## 数据契约

### `organization_unit` 扩展

- 现有：`id`、`code`、`name`、`parentUnitId`、`managerUserId`、`status`、审计时间。
- 新增可选字段：`unitType`、`unitLevel`、`standardCode`、`areaCode`、`category`、`sortOrder`、`description`。
- 保持：编码唯一；父级必须有效；禁止自引用和循环；负责人必须是启用账号。

### `organization_membership`

- 一个账号可属于多个部门，`isPrimary=true` 的唯一主部门驱动直属上级解析。
- 关系保存岗位/职务 `title`；将成员设为主部门时，同事务撤销其其他主部门标记。
- 移除关系前后都写授权审计；若移除主部门，流程解析明确返回“未配置直属上级”，不静默降级到无关用户。

### 组织权限组

- 新增部门到 IAM 系统角色的绑定表；只允许绑定 `scope=system` 且非 `system_admin` 的角色。
- 部门成员实时继承绑定角色，不复制为逐用户冗余数据；解绑后权限立即失效。
- 权限查询、角色候选人和流程角色键使用同一绑定关系，保证组织页添加权限后流程引擎直接可用。

## 页面交互

1. 系统配置中的组织架构卡片只展示说明和“打开组织架构管理”按钮。
2. 独立页顶部提供“返回系统配置”“新增根部门”“新增子部门”“添加成员”“绑定权限组”。
3. 左树支持搜索、展开/收起、选中；禁用部门仍显示但有弱化状态。
4. 右侧按 Tab 拆分：
   - 部门概览：字段、负责人、父部门、审计信息和编辑入口。
   - 成员与岗位：成员表、主部门标识、未分配账号提示、移除动作。
   - 权限组：部门继承的系统角色及解绑动作。
5. 新增同级/子级由选中节点菜单进入弹窗；新增成功后选中新部门。
6. 窄屏下树与内容纵向排列，表格保持横向滚动，不隐藏权限或审计字段。

## 安全路由与返回

- `#/system/organization` 仅为恢复提示；服务端 `adminProcedure` 仍是当前管理授权边界。
- 非管理员访问该哈希时回退 `#/flows`；系统配置、身份权限和组织架构之间的前进/后退由现有 `popstate`/`hashchange` 恢复。
- 页面查询失败显示错误状态，不回显数据库连接或内部 SQL。
