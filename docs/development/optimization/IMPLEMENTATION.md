## 四个新增模块

这些模块共用迁移 `0049_governed_capabilities`。它增加六张表，并允许等待订阅记录持久子调用。无需录入 BDP 地址或交付 BDP 凭据。用户明确本系统自管身份，外部数据连接器使用另行部署的 HTTP 与文件交换测试服务。

| 编号 | 正常业务入口 | 本地和浏览器验收 |
| --- | --- | --- |
| [G01 版本化数据连接器](G01-IMPLEMENTATION.md) | 项目资源、数据流节点及运行监控。API 分页和 CSV 绑定固定资源版本，外部写回先预览再确认 | MySQL 覆盖逐页恢复、限额、撤权、取消、目标拒绝和响应丢失；Edge 通过资源页上传、运行及最终结果回读，UTF-8 多行内容和原文件 SHA-256 一致 |
| [G02 持久父子调用](G02-IMPLEMENTATION.md) | 子流程节点编辑固定发布版本，父子实例详情分别鉴权 | 两轮独立 MySQL 回归均为 9/9，覆盖父等待、子终态重放、失败策略及取消竞争。Edge 从父实例导航至子实例再返回，真实 HTTP 办理子任务后读到父成功 |
| [G03 内部目录导入](G03-IMPLEMENTATION.md) | 业务中心导入菜单、人员与权限的组织架构。观察者预览，身份管理员应用 | 隔离库和 HTTP 实测预览业务零写入、并发几行只产生相应对象、改名后旧提交被拒。390px Edge 确认三行、重开批次、反向回退三行并恢复焦点 |
| [G04 助手后台回合](G04-IMPLEMENTATION.md) | 客户助手、管理试聊及助手运维。按原请求观察排队、取消、完成或待核对 | 真实 Edge 双标签在应用中断后由独立消费者接管，写入一条回复和一次修订。受控模型的六会话试验 6/6 成功，接单 108–127 ms，端到端样本 P95/P99 均 2575 ms |

0049 上线前保存私有备份并核对 gzip 完整性和 SHA-256。回退前停止新接单，按各模块交接文档排空已提交的父子调用、助手回合及待核对外部写回，再切换兼容镜像。完整恢复数据库需要单独的恢复点和还原演练。

## 验收边界

四档 CSS 宽度、键盘、焦点、DOM 命中、减少动效和 Chromium 中断恢复有自动化证据。物理手机输入法、真实辅助技术和业务高峰吞吐仍需独立样本。小规模模型试验的百分位仅描述本次限定并发。机器队列在每个验收场景保留已验层级与未覆盖条件。
