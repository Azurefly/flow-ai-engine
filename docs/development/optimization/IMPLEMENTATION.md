## 验收边界

四档 CSS 宽度、键盘、焦点、DOM 命中、减少动效和 Chromium 中断恢复有自动化证据。物理手机输入法、真实辅助技术和业务高峰吞吐仍需独立样本。小规模模型试验的百分位仅描述本次限定并发。机器队列在每个验收场景保留已验层级与未覆盖条件。

部署中的身份来自内部账号。本轮只核对了外部 OAuth、Forge 通知和对象存储配置项是否存在，结果均未配置。旧托管调度的真实上游删除也缺少可处置的专用旧任务。原生定时调度已用真实数据库、同一 UTC 时间桶和三个扫描进程验证只发起一个运行。对应外部服务日后启用时，可按[审计报告](REPORT.md)中的上游凭据、回执与样本条件补验。
