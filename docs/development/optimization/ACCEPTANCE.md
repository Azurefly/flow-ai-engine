# 优化验收场景

下表保留 A01–A67 的验收设计和通过条件。每条最新结果写在[机器可读队列](queue.json)对应编号的 `status` 和 `verification` 中，可直接读取已经验证的条件和仍需覆盖的子场景。本轮版本、环境与远程业务回执见[实施与验收记录](IMPLEMENTATION.md)。审计基线逐项运行数据保存在本机离线交接包的 `executed-tests.json`。

缺省准备为新建的隔离项目和合成账号，各次运行的前缀独立。需要两次提交使用同一键、同一代号或同一版本的用例，在该用例内保持不变。数据库核对以本轮项目、请求、作业或运行 ID 为范围。发布态与草稿态、试聊与客户入口分别取证。

## F03–F04　业务导入

交接包 `fixtures/` 含 `quoted.csv`、`multiline.csv`、`unclosed.csv`、`batch-invalid.csv`、`batch-corrected.csv`。五个文件均为 UTF-8 BOM 与 CRLF。多行说明含字段内真实 CRLF；无闭引号是刻意保留的坏文件。批次后两个文件使用同一 A/B 代号，在干净的合成所有者范围内配对使用。
