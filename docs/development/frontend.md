# 前端开发约束

## 页面入口和状态所有权

当前产品支持电脑网页端。常规回归使用桌面浏览器，涉及布局时覆盖桌面窗口缩窄或浏览器缩放。交互验收包含键盘操作、焦点返回和受影响控件的可访问名称。

[Home.tsx](../../client/src/pages/Home.tsx)装配登录、业务中心、编辑器、仓库、工作台与系统配置。[console-route.ts](../../shared/console-route.ts)负责解析和生成哈希路由。新增可分享的页面或详情定位时，同时验证直达、刷新、前进、后退，以及任务返回实例的位置。现有项目工作区和系统设置的部分页签在组件内管理，设计深链接时需要显式定义其语义。

流程、人员与资源的授权以当前服务端数据为准。组件状态保存编辑中的值，React Query 缓存保存已读取的数据。切换账号、项目或实例时，核对缓存键与草稿归属。权限读取失败、目录为空、真正无权、服务端写入成功但刷新失败分别给出可操作的界面状态。[资源填写会话](../../shared/resource-draft-session.ts)和[设置草稿](../../shared/system-settings-draft.ts)提供现有实现。

## 表单和命令

| 时刻 | 用户应能看到或继续做什么 |
| --- | --- |
| 首次填写 | 显示字段含义、单位、默认值和空值语义。布尔 `false`、数字 `0`、空串与缺失值分别处理。 |
| 提交中 | 固定对象和所读版本，锁定这一次提交。保留请求标识，避免回车和按钮各派发一次。 |
| 字段错误 | 指到业务字段或文件行列，中文展示原因和可接受范围。批次说明已成功、失败及待处理项。 |
| 版本冲突 | 保留本地内容，提供查看新版本、导出或重新确认入口。重新确认后提交新版本。 |
| 响应中断 | 对支持请求核对的命令先核对同一请求。尚无核对接口的操作明确告诉用户如何查找结果。 |
| 保存成功 | 结束该次编辑。随后列表加载失败可单独重试。返回后重复打开检查实际保存值。 |

交互尽量复用 [CreationDialog](../../client/src/components/CreationDialog.tsx)、现有检索选择器和权限反馈组件。导入器先读完整逻辑记录，再做业务校验。选中控件的可访问名称可能包含成员数、状态或流程名，测试通过角色、名称及页面范围定位。

开发服务的 `.manus-logs/` 供本机定位问题。网络日志记录请求路径、方法、状态和耗时。页面事件记录动作、控件类型与视口，控制台记录级别、参数个数和可用的错误源码位置。新增采集字段时，同步更新浏览器采集和服务端写入使用的白名单，用合成数据检查查询参数、认证头、Cookie、请求与响应正文、输入值及错误原文均未进入日志。[采集契约](../../scripts/dev/debug-log-metadata.mjs) · [回归用例](../../server/debug-collector.test.ts)

## 画布与数据表

- 节点允许类型、入口出口、默认参数来自共享契约。新增编辑器字段要覆盖创建、粘贴或导入、修改、保存重开、预检和运行快照。持久化字段改名要有存量读取或显式转换路径。
- 画布保存、发布和运行前提交仍聚焦的字段编辑。连线 ID、端口、路由优先级、默认分支在保存导出再导入后保持语义。预检诊断可定位到节点和字段。
- 列表按服务端分页和权限过滤。详情读完整表单和执行上下文。长字段可读，空态和错误态分别渲染。保留原有完整列表 API 的调用约定。
- 浏览器复验覆盖桌面和受影响的窗口宽度、键盘操作与弹窗焦点。画布相关改动额外检查缩放、平移和面板滚动。暗色或动效修改实际切换对应设置。改动入口或分包后，在空缓存下核对登录页、业务首页的静态资源请求，再打开需加载对应资源的编辑器。

## 检查与交付

客户助手与管理试聊分别保留会话上下文。区分请求已接单、等待补充、等待确认、已提交和结果待核实。选择旧会话时显示原项目，确认卡片保留目标和影响。有正式运行回执时展示可查的运行编号。回执丢失查询原 `sessionId/requestId`，新操作使用新标识。[助手专项](assistant-review.md)

PowerShell 在仓库根目录运行 `pnpm check`、改动对应的 Vitest 用例和 `pnpm build`。构建预算由 [check-bundle-budget.mjs](../../scripts/check-bundle-budget.mjs)定义。记录失败的是单块、总量还是 HTML，以及使用的构建版本。浏览器复验记录视口、账号角色、输入、点击后的状态、刷新回读和截图。入口和用例映射见[开发索引](INDEX.md)。
