## 本轮的真实业务证据

- 真实 MySQL 覆盖身份、组织、项目、独立审核、发布恢复、参与人撤回与重提、成员权限、HTTP 节点、数据读取、作业租约与崩溃恢复。隔离服务通过 HTTP 实跑并行人工、消息等待、循环、签署、任务移交、关联、去重、三种流程仓库往返。浏览器写入业务、部门、工作域，保存画布并刷新、在任务页提交同意后回读实例完成。
- 数据调度实际跨过一个分钟触发点，Worker 执行成功，过期 revision 被拒，暂停和删除均回读验证。另在专用 MySQL 人为等待的单一查询中取消运行，先观察数据库确有正在等待的读取。取消后状态保留、后继未执行，释放源表后 Worker 收尾。
- 远程系统模型目录、固定文本对话、正式产品的流程 LLM 节点、IAM 账号预览和客户助手各有独立实测。助手生成业务目录提案，确认前后条数为 0、1，重放仍为 1。两个远程合成业务归档后分别核对了活动业务集合。
- 以真实 Edge 检查 1440px 和 390px、弹窗焦点及两种动效偏好。CSS 减少动效和画布直接定位已生效。界面取舍参考了 Motion、AutoAnimate、Radix 与 xyflow 的固定提交。[开源实现与本站验收](ui-motion-review.md)

联合 OAuth、旧托管通知/心跳与对象存储服务在最后核对的部署缺少上游配置。未做第三方真实交付。生产备份恢复、客户专属连接、真机软键盘和目标负载尚需独立验收。完整复验记录在本次工作区的 `.cache/functional-audit-20261119/AUDIT.md`，可提交的长期入口为[开发索引](INDEX.md)。
