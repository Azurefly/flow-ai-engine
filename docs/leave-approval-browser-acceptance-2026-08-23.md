# 请假审批多规则路由验收记录（2026-08-23）

## 验收目标

- 流程图明确采用“状态 → 操作 → 路由（多规则）→ 多个人员状态”。
- 员工申请后，员工进入“等待审核”，直属上级进入“待审批”。
- 直属上级可在待办中执行“审核通过”；员工无操作。
- 直属上级通过后自动补充经理：员工进入“直接上级审核通过，待经理通过”，直属上级进入“已审核”，经理进入“待审批”。
- 经理通过后：员工进入“申请通过”，直属上级和经理均进入“已审核”。
- 节点、配置面板和路由规则编辑保持参考项目前端的卡片、分类页签和路径列表语义。
