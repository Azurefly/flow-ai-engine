# 页面交互与导航规划（2026-08-23）

## 交互原则

1. 顶层四个工作区使用同级切换：流程设计、已启动流程、流程仓库、系统配置。
2. 业务、流程详情、设计器和实例详情属于逐级深入；返回按钮必须回到真实来源页面，而不是固定跳转。
3. 页内不同数据视角使用 Tab，不伪装成返回操作；弹窗仅承载短表单、确认和单条详情。
4. 写操作完成后留在当前工作上下文；删除当前对象后返回其来源列表。
5. 页面标题区必须同时说明“当前位置、返回去向、主要操作”，避免仅靠图标猜测。

## 主要入口去向矩阵

| 当前页面 | 操作 | 交互类型 | 目标/返回语义 |
| --- | --- | --- | --- |
| 顶层导航 | 流程设计/已启动流程/流程仓库/系统配置 | 同级 Tab | 切换工作区并清理不适用的子页面状态 |
| 业务中心 | 打开业务 | 进入下一级 | 进入项目工作区；返回业务中心 |
| 项目流程中心 | 详情 | 进入下一级 | 打开流程详情；返回当前项目流程中心 |
| 项目流程中心 | 设计/创建并设计 | 进入下一级 | 打开设计器；返回当前项目流程中心 |
| 流程详情 | 进入设计器 | 进入下一级 | 打开设计器；设计器返回流程详情 |
| 流程仓库 | 打开设计器 | 跨工作区深入 | 切换到流程设计器；设计器返回流程仓库 |
| 设计器侧栏 | 切换流程 | 同页对象切换 | 保持设计器与原返回来源，只替换当前流程 |
| 设计器 | 后端运行 | 跨工作区深入 | 打开已启动流程的运行监控；可切回流程工作台 |
| 已启动流程 | 流程工作台/运行监控 | 页内 Tab | 同一工作区内切换，不使用“返回上一级”文案 |
| 系统配置 | 身份与权限 | 进入下一级 | 打开身份管理；返回系统配置 |
| 实例详情、编辑表单 | 关闭/取消 | 弹窗关闭 | 回到打开弹窗的当前页面，不改变工作区 |

## 第一轮改造

- 记录设计器真实来源：业务中心、项目流程中心、流程详情或流程仓库。
- 设计器提供带明确文字的返回按钮，并按来源返回。
- 从流程详情进入设计器后，返回详情；从流程仓库进入后，返回仓库。
- 让此前不可达的运行监控成为“已启动流程”工作区内的正式 Tab。
- 后端运行成功后进入运行监控，而不是丢失选中运行并回到工作台首页。
- 删除当前流程后返回真实来源列表。
- 对上述交互补充源码回归约束。
